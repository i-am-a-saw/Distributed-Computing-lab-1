Параллельное вычисление точек множества Мандельброта

Сборка:
  g++ -std=c++17 -O2 -pthread program_pthreads.cpp -o program

Запуск:
  ./program nthreads npoints

Пример:
  ./program 8 100000

Выходной файл: mandelbrot.csv (создаётся/перезаписывается в текущем каталоге).
Формат CSV: x,y

Примечание: принадлежность множеству проверяется численно, максимум 1000 итераций.
